⚛️ Understanding Bloch Spheres

The Bloch sphere is a geometric representation of a quantum state. Each point on the sphere represents a possible quantum state of a single qubit.

X
Y
Z

Key Components:

  • North Pole (|0⟩): Represents the computational basis state |0⟩
  • South Pole (|1⟩): Represents the computational basis state |1⟩
  • Equator: Represents superposition states
  • X-Axis: |+⟩ and |-⟩ states
  • Y-Axis: |+i⟩ and |-i⟩ states
  • Z-Axis: |0⟩ and |1⟩ states

🔧 Quantum Gates Reference

H (Hadamard)

Creates superposition: |0⟩ → (|0⟩ + |1⟩)/√2

h q[0];

X (Pauli-X)

Bit flip: |0⟩ → |1⟩, |1⟩ → |0⟩

x q[0];

Y (Pauli-Y)

Phase and bit flip

y q[0];

Z (Pauli-Z)

Phase flip: |1⟩ → -|1⟩

z q[0];

CNOT

Controlled NOT gate

cx q[0], q[1];

RX, RY, RZ

Rotation gates around X, Y, Z axes

rx(π/2) q[0];

📋 Data Format Guide

Live Data Stream Format

{
  "num_qubits": 2,
  "frames": [
    {
      "bloch": [
        [0, 0, 1],    // Qubit 0: |0⟩ state
        [1, 0, 0]     // Qubit 1: |+⟩ state
      ]
    }
  ]
}

Manual JSON Input Format

{
  "num_qubits": 2,
  "frames": [
    {
      "bloch": [
        [0.707, 0, 0.707],  // Qubit 0
        [0, 0.707, 0.707]   // Qubit 1
      ]
    }
  ]
}

🚀 Usage Examples

Basic Quantum Circuit

OPENQASM 2.0;
include "qelib1.inc";
qreg q[2];
creg c[2];

h q[0];        // Create superposition
cx q[0], q[1]; // Create entanglement
measure q[0] -> c[0];
measure q[1] -> c[1];

This creates a Bell state: (|00⟩ + |11⟩)/√2

Entangled State Analysis

OPENQASM 2.0;

Creates a GHZ state: (|000⟩ + |111⟩)/√2
